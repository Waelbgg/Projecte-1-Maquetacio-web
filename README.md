# Proyecto 1 — Maquetación Web

## Maquetación de un CV responsive con HTML5 y CSS3

Este proyecto forma parte de la **IA1 del módulo M0373 — Lenguajes de marcas y sistemas de gestión de información**, del ciclo formativo de Desarrollo de Aplicaciones Web (DAW).

El objetivo es crear una página web de un currículum personal utilizando HTML5 y CSS3, tomando como referencia un diseño de Figma. La idea es conseguir que el resultado sea lo más parecido posible al diseño original y que se adapte correctamente a diferentes tamaños de pantalla.

Además de ser un proyecto de clase, quiero aprovecharlo como una primera base para desarrollar en el futuro mi propia página web profesional, donde pueda presentar mi perfil, mis proyectos y las habilidades que vaya adquiriendo durante mis estudios.

## Diseño de referencia

El diseño utilizado para realizar este proyecto es la plantilla **2020 Responsive Resume Kit**, disponible en Figma.

**Enlace al prototipo:**  
[2020 Responsive Resume Kit — Figma](https://www.figma.com/design/uCkrARBj4VWVw6e79uw6X6/2020-Responsive-Resume-Kit--Community-?node-id=19-84)

## Objetivos

- Reproducir el diseño de Figma lo mejor posible.
- Crear la estructura de la página utilizando HTML5.
- Diseñar la página con CSS3 propio.
- Adaptar el currículum a móvil, tablet y ordenador.
- Utilizar Flexbox y/o Grid para organizar los elementos.
- Trabajar con variables CSS para los colores y las tipografías.
- Utilizar media queries para adaptar el diseño a cada pantalla.
- Organizar el proyecto y guardar los cambios mediante Git y GitHub.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox y CSS Grid
- Media Queries
- Google Fonts
- Git
- GitHub

No se utilizarán frameworks CSS ni librerías de componentes. Todo el diseño se realizará con CSS propio.

## Diseño responsive

La página se desarrollará empezando por la versión móvil y después se irá adaptando a pantallas más grandes.

- **Móvil:** 375–414 px aproximadamente.
- **Tablet:** 768–1024 px aproximadamente.
- **Ordenador:** desde 1280 px aproximadamente.

## Fases del proyecto

1. Crear el repositorio en GitHub y preparar el proyecto.
2. Revisar el diseño original de Figma.
3. Crear la estructura HTML.
4. Añadir los estilos generales con CSS.
5. Maquetar la versión móvil.
6. Adaptar el diseño a tablet y ordenador.
7. Revisar que todo funcione correctamente en los diferentes tamaños.
8. Realizar los últimos cambios y preparar la entrega.
